# Janateyn Yemeni Restaurant Website

A responsive restaurant landing page made with HTML, CSS and vanilla JavaScript. The included `assets/` folder contains the restaurant photos supplied for this project.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in your browser.

For local hosting, you can also run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Customize
- Edit restaurant copy, menu highlights, phone and address in `index.html`.
- Replace photos in `assets/` and update matching image paths in `index.html` / `styles.css`.
- The directions button opens a Google Maps search for Janateyn Yemeni Restaurant in Djibouti.
- The phone buttons use `+253 77 81 90 90`.

Menu items and prices are intentionally described as highlights; confirm the current menu and prices with the restaurant before publishing.
